# UI Style Mockups

This folder contains 6 distinct UI style options for the Lidarr Spotify Scraper V2 redesign.

## How to View

Open any HTML file directly in your browser:

```bash
# From the project root
open v2/apps/web/mockups/01-dark-luxe.html
# or use your preferred browser
firefox v2/apps/web/mockups/02-editorial-clean.html
```

Each mockup includes a **theme toggle button** (☀️/🌙) in the header to switch between light and dark modes.

## The Options

| # | Name | Aesthetic | Fonts | Key Features |
|---|------|-----------|-------|--------------|
| 01 | **Dark Luxe** | Premium, sophisticated | Playfair Display + Source Sans 3 | Gold accents, serif elegance, subtle animations |
| 02 | **Editorial Clean** | Magazine-inspired | Libre Baskerville + Manrope | Red accent, clean typography, editorial layout |
| 03 | **Neo-Brutalist** | Bold, raw, honest | Work Sans + Space Mono | Hard shadows, visible structure, high contrast |
| 04 | **Soft Gradient** | Friendly, approachable | Nunito + DM Sans | Purple gradients, rounded corners, soft depth |
| 05 | **Vinyl Retro** | Warm, analog, nostalgic | Archivo Black + Karla | Cream/orange palette, record-sleeve inspired |
| 06 | **Midnight Modern** | Futuristic, polished | Sora + Outfit | Glass-morphism, vibrant gradients, glow effects |

## What to Look For

When reviewing each mockup, consider:

1. **Overall Vibe** — Does it feel right for a music library app?
2. **Light vs Dark Mode** — Use the toggle to check both
3. **Typography** — Is the heading/body font combination readable and appealing?
4. **Color Palette** — Check the "Style Reference" section at the bottom
5. **Component Styling** — Cards, buttons, sidebar navigation
